# Security Policy

## Supported version

Security reports should target the latest version in this repository. NEXA is currently a personal/development release; no service-level response time is guaranteed.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Contact the repository owner privately through the contact method listed on the GitHub profile and include:

- A concise description of the issue
- Steps to reproduce and potential impact
- A suggested mitigation, if known

Do not include passwords, private user data, or live secrets in a report. If no private contact method is available, open a minimal issue asking for a private reporting channel without disclosing the vulnerability details.
