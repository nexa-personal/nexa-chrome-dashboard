# Contributing to NEXA

Thanks for taking an interest in NEXA.

## Before opening an issue

- Check whether a similar issue already exists.
- Include your Chrome version and operating system.
- Describe the exact steps needed to reproduce the problem.
- Include the complete error message and screenshots when useful.
- Never post passwords, access tokens, private URLs, or other secrets.

## Pull requests

- Keep changes focused and explain the reason for the change.
- Preserve the no-build-step extension structure unless a change is discussed first.
- Check `manifest.json` is valid JSON and run `node --check app.js` when Node.js is available.
- Test the extension by loading the repository folder through `chrome://extensions` with Developer mode enabled.
- Document user-visible changes in `CHANGELOG.md`.

By submitting a contribution, you confirm that you have the right to submit it. Because the current project license reserves all rights, please open an issue to discuss licensing and permission before submitting substantial code contributions.
